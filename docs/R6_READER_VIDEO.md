# R6 reader video notes (Sajda, owner-recorded)

Source: `~/Downloads/ScreenRecording_09-09-2026 18-39-32_1.MP4`, 139 s,
iPhone screen recording of the Sajda Quran reader. Reviewed 2026-09-09 as 14
frames at 10 s intervals (f_001–f_014). This file exists because other models
cannot watch the video; it is the full visual record for R6 slices C–G.

## Page layout (focused reading)

- Page header, top-LEFT, quiet secondary text: the range of verses ON THE
  PAGE, e.g. `Yunus: 107-109` (f_001), `Yunus: 7-14` (f_005). Not the
  collection range. (Owner override for Hadithly: our corner label shows the
  whole VOLUME range instead — see PLAN.md R6 record.)
- Markers: small dim `10:107`-style labels (`surah:ayah`) above each verse.
  Arabic block RIGHT-aligned (RTL); translation block LEFT-aligned (LTR).
  No dividers anywhere; whitespace separates items.
- Verse-end ornament: a small medallion with the ayah number inline at the
  end of the Arabic text (f_001: `107`, `108` medallions).
- Saved state: tiny inline icons right after the marker — orange bookmark,
  pink heart (f_006 beside `7:182`). Non-interactive indicators, no buttons.
- Thin scroll-progress capsule: short, centered, neutral gray, just under the
  status area (f_002). Present while focused; fills/defills with scroll.
- Revealed (unfocused) top pills, centered: `209 page` and `11 juz`
  (f_005). Our equivalent: page pill + volume/chapter pill.
- End-of-page buttons: two wide pills side by side, `< 209 Page` and
  `207 Page >` — neighbor page numbers, chevrons at the OUTER corners of
  each pill (f_002 end image). (Owner override for Hadithly: chevrons snug
  INSIDE our pills, close to the label.)
- New-section opening (f_007: `Hud`): centered title, small subtitle line
  (`Makkan · Hud · 123 Ayah`), then a large calligraphic divider. Our
  equivalent: centered volume title + `N hadiths` line (no ornament).

## Chrome and bottom menu

- Focused view: no chrome except the thin progress capsule. Status bar
  hidden while focused, visible when revealed.
- Revealed view: NO top header. Bottom-LEFT green-ring circular back button,
  bottom-RIGHT circular hamburger menu button (f_003).
- Menu expands UPWARD from the bottom-right as stacked rounded cards
  (f_005, f_006): location card (`Name`, `Name · 109 Ayah · Makkan`, green
  medallion with number) → `Bookmarks & Notes` row (bookmark icon right) →
  `Settings` row (`Page · Қазақша` subtitle, AA icon right) → bottom action
  row of three round buttons (play, bookmark, search) → X dismiss circle at
  the very bottom-right. Menu bottom row bookmarks the POSITIONED item.
- Any scroll or menu-open collapses back to the focused view.
- `Add bookmark` sheet (f_014): title plus stacked pill options `Start of
  page` / `Current ayah 11:4` / `Cancel`. (Hadithly: per-hadith bookmarks;
  bookmark-placement choice is H3 scope, not R6.)
- Notes sheet (f_007): bottom sheet with verse snippet + medallion, note
  text (`Didn't know that`), green action bar (delete left, `AT-TAWBA: 30`
  center, share right). H3 scope, reference only.

## Contents sheet (f_004)

- Bottom sheet with grabber + X top-right, segmented `Surah | Juz` tabs
  (Juz grouping is Quran-only — REJECTED for Hadithly), section headers
  (`Juz 13`…), rows with green medallion number + name + translated name +
  ayah-count icon, right-edge numeric index rail (unnecessary for our short
  lists — rejected).

## Settings sheets (f_008, f_009, f_010, f_011)

- Settings: `READING MODE` cards (`Page | Surah | Mushaf` — Quran-only
  modes, rejected), `SETTINGS` rows with chevrons (Arabic font, translation
  with flag, reciter — rejected), `DISPLAY` toggle pills (Arabic,
  Translation, …). Our R4 settings already mirrors this minus rejected rows.
- Font sheet: `FONT SIZE` preview box + `A− | A+` stepper + font list with
  live preview and blue checkmark. Already mirrored in R4.
- Translation picker: preview + stepper + `SYSTEM LANGUAGE` / `OTHER`
  grouped rows with flag icons and download icons. Reference for future
  translation-source UI, not R6.
- Search sheet (f_012, f_013): grabber + X + search field, grouped results
  with highlighted matches and `Surah · ayah N · page M` subtitles. Search
  stays deferred — aesthetic reference only.
